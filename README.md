# Polymath Studio — Equation Solver

공학 수식을 직접 입력하고 파라미터를 움직이며 해의 변화를 탐색하는 브라우저 계산기입니다. **Equation Solver** 카테고리 안에 **Linear**와 **Nonlinear**를 제공합니다. Differential Equation Solver는 이후 확장할 별도 카테고리이며 아직 실행할 수 없습니다.

## 실행하기

Node.js 22 이상과 npm을 권장합니다. 저장소 디렉터리에서 실행하세요.

```sh
npm ci
npm run build:wasm
npm run dev
```

Vite가 표시하는 주소로 접속합니다. Codespaces에서는 실행 중인 서버를 `Ctrl+C`로 종료하고 업데이트하세요. `npm run dev`가 실행 중인 터미널은 서버 입력을 받으므로, Git 명령은 서버를 중단하거나 새 터미널에서 입력합니다.

```sh
 git pull --ff-only origin codex/leq-studio
 npm ci
 npm run dev -- --port 5173 --strictPort
```

Git이 로컬 변경 때문에 업데이트를 중단하면 해당 변경을 보관한 뒤 업데이트해야 합니다. 배포용 정적 파일은 `npm run build`로 `dist/`에 생성하고 `npm run preview`로 확인합니다. `build`는 WASM 재컴파일, TypeScript 검사, Vite 빌드를 포함합니다. 별도 Python·백엔드·API 키는 필요하지 않습니다.

## 계산기 구성과 저장

- **Linear**는 예제 없이 빈 모델에서 시작합니다. 한 줄에 하나의 방정식을 입력합니다.
- **Nonlinear**도 빈 모델에서 시작하며 **예제 불러오기**로 학습용 모델 5개를 선택할 수 있습니다.
- **새 모델**은 현재 유형의 빈 모델을 엽니다. 알림의 **되돌리기**로 직전 모델을 복원할 수 있습니다.
- Linear/Nonlinear는 각각의 작업 초안을 유지합니다. 탭을 바꾸어도 작성한 수식과 파라미터를 보존합니다.
- 기존 버전의 프로젝트 JSON과 로컬 저장 내용도 불러올 수 있습니다. 유형(`mode`)이 없는 기존 파일은 Linear로 해석합니다. 기존 사용자 모델은 업데이트 시 삭제하지 않습니다.

현재 모델과 유형별 초안은 브라우저 `localStorage`에 저장됩니다. **프로젝트 저장**은 JSON을 내려받고 **불러오기**는 JSON을 검증해 복원합니다. Nonlinear 파일에는 `mode: "nonlinear"`가 포함됩니다. 예제를 불러오면 현재 모델을 교체하므로 보관할 모델은 JSON으로 저장하세요. 저장소 접근이 차단되어 있으면 자동 저장 불가 상태를 표시합니다.

## Linear 사용법

숫자·미지수와 `+ - *`로 선형식을 작성합니다. `2x`, `2 x`, `2*x`는 같은 뜻입니다. 선형성을 유지하는 괄호와 알려진 값으로의 나눗셈도 지원합니다. `#` 뒤는 주석입니다.

```text
2x + y = 10
x - y = 2
```

미지수는 계산으로 구할 값입니다. 파라미터 패널에 등록한 이름은 알려진 값으로 취급합니다. 예를 들어 `x + y = F`에서 F를 파라미터에 등록하면 x와 y만 미지수입니다. 수식에 `F = 100`을 입력하면 그 줄도 방정식 하나로 처리합니다.

방정식 수와 미지수 수가 같아야 하고, 유일해를 얻으려면 식들이 독립적이어야 합니다. `x*y`, `x^2`, `sin(x)` 같은 비선형식은 Nonlinear로 작성해야 합니다. 이름은 영문자로 시작하며 영문·숫자·밑줄을 사용하고 대소문자를 구분합니다. 소수점은 `.`이며 과학적 표기 `1.2e-3`도 사용할 수 있습니다. Linear는 최대 64개 미지수를 지원합니다.

## Nonlinear 사용법

첨부된 PolymathPlus NLE 문서의 `NLE0 / NLE1 / NLES` 형식을 바탕으로 구현했습니다. 함수·거듭제곱을 포함한 식을 안전한 파서로 해석하며 `eval`을 사용하지 않습니다.

### 한 미지수: 잔차식과 탐색 구간

등식 양변을 한쪽으로 모아 `f(x)` 오른쪽이 0이 되도록 적습니다. 최소·최대 구간은 숫자로 지정하고 변수 이름을 맞춥니다.

```text
f(x) = x^2 - 4
x(min) = 0
x(max) = 3
```

이 구간에서는 x=2를 찾습니다. 구간을 -3~0으로 바꾸면 x=-2를 찾습니다. 구간 양 끝에서 잔차의 부호가 반대이거나 끝점 자체가 근이어야 합니다. 부호가 같으면 다른 구간을 지정해야 하며, 모든 근을 자동으로 찾는 방법은 아닙니다. 불연속점의 부호 변화만으로는 수렴으로 처리하지 않습니다.

### 연립 비선형식: 잔차식과 초기 추정값

각 미지수에 대응하는 `f(이름)`과 초기 추정값 `이름(0)`을 입력합니다.

```text
f(x) = x^2 + y^2 - 25
f(y) = x - y - 1
x(0) = 4
y(0) = 3
```

이 시작점에서는 (4,3)을 찾습니다. 초기값을 (-4,-3)으로 바꾸면 다른 교점 (-3,-4)을 찾을 수 있습니다. 감쇠 Newton 반복이 수렴하지 않으면 초기값·정의역·수식 스케일을 확인하도록 안내합니다. 결과의 **수렴**은 하나의 해를 찾았다는 뜻이며, 유일해를 뜻하지 않습니다. 최대 16개 근 변수와 200회 반복을 지원합니다.

### 보조식과 명시식 계산

반복되는 수식은 이름을 붙여 분리할 수 있습니다. 보조식은 정의 순서와 관계없이 의존 관계를 분석하며, 중복 정의·순환 참조·정의되지 않은 이름을 거부합니다.

```text
f(x) = t + 4*x^2 - 1620
t = x*log(x/2)
x(min) = 0.1
x(max) = 100
```

`log`/`log10`은 상용로그, `ln`은 자연로그입니다. 위 예제의 근은 x=20입니다. `sin`, `cos`, `tan`, `exp`, `sqrt`, `abs` 등의 실수 함수와 `pi`, `e`도 지원합니다. 함수는 라디안 기준입니다. 정의역을 벗어나거나 값이 유한하지 않으면 오류를 표시합니다.

근 선언 없이 명시식만 작성하는 NLE0도 지원합니다.

```text
a = 1
b = 4
x = a + b^2
x + 2
```

명시식과 익명 표현식 결과를 계산하며, 근 찾기·Jacobian 조건수는 적용하지 않습니다. `#@` 해법 지정 지시문, 제약 초기값(`x(0)=0.5 >0`), 부등식 제약은 이번 버전에서 지원하지 않으며 오류로 안내합니다. 원본 PolymathPlus의 전체 문법·파일 형식 호환을 제공하는 구현은 아닙니다.

| 모델                               | 기본 결과  | 배울 내용                   |
| ---------------------------------- | ---------- | --------------------------- |
| 제곱식의 양의 근                   | x=2        | 잔차식·구간·파라미터        |

## 시뮬레이션과 리포트

수식이나 파라미터를 수정하면 자동으로 계산합니다. **모델 풀기** 또는 `Ctrl/Cmd+Enter`로 다시 계산할 수도 있습니다. 파라미터 숫자 입력란은 Enter 또는 포커스 이동 시 적용하며, 슬라이더는 즉시 반영됩니다.

그래프는 별도 렌더링 지점으로 곡선을 그리고, **표와 CSV는 설정한 파라미터 간격**을 따릅니다. 예를 들어 `0.2~0.8`, 간격 `0.01`이면 61행입니다. 최댓값이 나누어떨어지지 않으면 마지막 행에 최댓값을 한 번 포함하고 마지막 구간이 짧다는 안내를 표시합니다. 그래프·표 선택은 같은 계산 지점을 가리킵니다.

표·CSV는 Linear 최대 2,000행, Nonlinear 최대 500행입니다. 초과 시 간격을 임의로 바꾸지 않고 조정 안내를 표시하며, 현재 해와 그래프는 유지합니다. Nonlinear의 각 탐색 지점은 동일한 초기값·구간에서 독립적으로 풉니다. 모든 정상상태나 해 분기를 자동 추적하는 기능은 아니며, 실패한 지점은 `해 없음`과 빈 CSV 결과로 남깁니다. 그래프는 시간에 따른 미분방정식 적분이 아닙니다.

리포트는 Markdown, 계산 데이터는 CSV로 저장합니다. Linear의 계수 행렬과 Nonlinear 수렴점의 Jacobian은 리포트의 접기/펼치기 상세 영역에서 검토합니다. 비선형 리포트는 계산 방법·반복 횟수·잔차·보조식 결과를 제공합니다.

## 조건수와 민감도

리포트에서 기존 **∞-norm** 또는 **2-norm(SVD)** 을 선택합니다. `κ∞(A)=||A||∞·||A⁻¹||∞`, `κ₂(A)=σmax/σmin`이며 2-norm은 `ml-matrix`의 직접 SVD로 계산합니다. `AᵀA`를 만드는 방식은 사용하지 않습니다. 선택은 프로젝트 JSON·자동 저장·리포트에 반영됩니다.

| 조건수 κ         | 참고 표시        |
| ---------------- | ---------------- |
| 1 ≤ κ < 10⁴      | 초록 · 안정      |
| 10⁴ ≤ κ < 10⁸    | 노랑 · 민감      |
| κ ≥ 10⁸ (∞ 포함) | 주황 · 매우 민감 |
| 계산 실패        | 회색 · 판정 불가 |

Linear는 행별 정규화 전의 원래 계수 행렬 A를, Nonlinear는 해 주변의 수치 Jacobian J를 진단합니다. 비선형 조건수는 국소 정보이며 전역 수렴이나 유일성을 보장하지 않습니다. 특히 1×1의 비영 Jacobian은 행렬 조건수가 1이므로, 단일근의 실제 민감도는 도함수 크기·측정 오차와 함께 봐야 합니다. 색상은 참고 범위이며 단위·스케일·입력 정밀도에 따라 해석해야 합니다. 작은 잔차도 정확한 해를 보장하지 않습니다. 2-norm 선택 자체가 해 계산의 정밀도를 높이지는 않습니다.

## 아키텍처와 검증

React·TypeScript UI → 안전한 AST 파싱/캐시 → Web Worker 수치해석 → 반응형 그래프·표·리포트로 구성합니다.

- `src/engine/index.ts`: Linear 파서와 부분 피벗팅 가우스 소거법. `solver.wat`를 `wabt`로 컴파일한 WASM을 사용합니다.
- `src/engine/nonlinear-parser.ts`: NLE 잔차식·보조식·구간/초기값과 함수의 안전한 파서 및 의존 관계 검증.
- `src/engine/nonlinear.ts`: 단일근 구간 이분법과 명시식 평가는 JavaScript, 연립 Newton 보정은 실제 WASM 선형 커널을 사용합니다. WASM을 사용할 수 없는 경우에는 표시된 JavaScript 대체 경로를 사용합니다.
- `src/engine/conditioning.ts`: 원래 A 또는 수렴점 J의 ∞/2-norm 조건수와 민감도 분류.
- `src/engine/sweep.ts`: 그래프와 표의 계산 지점 분리 및 누적 오차 없는 간격 처리.

```sh
npm test
npm run build
npm run test:e2e
```

수치·파서·실제 WASM 회귀 테스트와 Chromium 사용자 흐름을 검증합니다. 브라우저 테스트는 시스템 `/usr/bin/chromium` 또는 Playwright Chromium을 사용합니다. 필요하면 `npx playwright install chromium` 또는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`를 설정합니다.

계산과 저장은 브라우저에서 수행하며 모델을 외부 서버로 보내지 않습니다. 앱·WASM 로드 후 현재 페이지는 네트워크 없이 계산할 수 있지만, 오프라인 새로고침/PWA·클라우드 계정 동기화·단위 자동 검증·최적화·ODE는 구현하지 않았습니다. 로컬 저장은 암호화된 비밀 저장소가 아닙니다.
